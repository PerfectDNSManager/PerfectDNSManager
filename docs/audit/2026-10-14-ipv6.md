# IPv6 par défaut et validation Android TV — 14 octobre 2026

## Défauts corrigés

La bêta 8 lisait `disable_ipv6` avec une valeur de repli `false` dans les réglages et le service VPN, mais `MainActivity` enregistrait automatiquement `true` lorsque la clé était absente. Vérifié dans le code et dans l’écran des réglages de l’APK public sur AVD Android TV 12 (API 31).

La bêta 9 retire cette activation automatique. `Ipv6Settings.initialize()` s’exécute dans l’application, avant toute activité ou service (y compris un démarrage automatique). Il remet une seule fois l’ancien réglage à `false`. Les anciennes versions ne distinguaient pas une valeur automatique d’une activation manuelle : cette remise à zéro concerne donc aussi les anciennes activations manuelles. Après migration, les choix de l’utilisateur et les imports sont conservés.

L’état affiché assimilait également toute absence de réponse IPv6 à « bloqué ✓ », même avec l’option OFF et sans VPN. L’écran et le rapport affichent maintenant « indisponible » dans ce cas. « Bloqué » n’est affiché que lorsque le VPN est actif et son option de blocage est activée.

## Vérification du trafic

`Ipv6RoutingInstrumentedTest` utilise un vrai échange TCP IPv6 depuis l’UID de l’application, sans protection de socket ni liaison au réseau physique. Une sonde sur le loopback IPv6 de l’hôte est accessible depuis l’AVD par `fec0::2`. Ce test ne dépend pas de la présence d’un accès Internet IPv6 chez le fournisseur d’accès.

```sh
python3 tools/ipv6_probe_server.py
# Dans un autre terminal, après installation des APK debug et androidTest :
adb -s emulator-5556 shell am instrument -w -e class app.perfectdnsmanager.Ipv6RoutingInstrumentedTest app.perfectdnsmanager.test/androidx.test.runner.AndroidJUnitRunner
```

Le test exige d’abord une connexion IPv6 fonctionnelle sans VPN, puis vérifie la séquence blocage OFF → ON → OFF. Les deux étapes OFF doivent recevoir `PDM_IPV6_OK` ; l’étape ON doit échouer. Il remet ensuite l’option sur OFF et arrête le VPN.

Ces tests sont réservés à un AVD jetable : ils modifient l’autorisation VPN, le DNS privé et les préférences réseau de PDM. Un essai AVD ne constitue pas une validation sur un Fire Stick physique.
