# Native 16 KiB compatibility — 2.4.9-beta.1

Changes: Conscrypt Android 2.5.2 → 2.8.0; Argon2kt 1.5.0 → 1.6.0. Both published AAR manifests retain minSdk 21 and all four native ABIs (armeabi-v7a, arm64-v8a, x86, x86_64). App minSdk 21, target/compile SDK 34 and APK package identity remain unchanged. Includes Android/site audit commits df9c6c1 and a541c58.

`tools/check_native_alignment.py` checks the actual APK: required libraries/ABIs, 64-bit ELF LOAD alignment/congruence, RELRO protection against writable-data overlap, and ZIP offsets for uncompressed 64-bit shared objects. The existing ADB binary uses an isolated RELRO LOAD; its unaligned end is safe only because page rounding does not overlap writable data. The tool rejects the old APK at libargon2jni ELF alignment. New local release APK passes for all 16 libraries, as does build-tools 35 zipalign -c -P 16 4.

Release CI now also checks the final APK's minSdk is exactly 21 and runs both alignment checks before publication. No minSdk overrideLibrary or removal of a 32-bit architecture is used.

Instrumentation tests exercise the production Argon2 derivation against an independent libargon2 vector, a loopback TLS 1.3 handshake with explicit trusted certificate and matching ADB exporter bytes, and the actual ADB SPAKE native client/server encrypt/decrypt exchange (API 30+ feature). Tests create no donation, upload or external connection. Emulator page size is asserted explicitly rather than inferred from its name.

Sources: https://developer.android.com/guide/practices/page-sizes ; https://github.com/google/conscrypt/releases ; https://github.com/lambdapioneer/argon2kt/releases . AAR artifacts inspected directly from Maven Central.
